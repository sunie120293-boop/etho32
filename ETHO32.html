ETHO · RESEARCH ARCHIVE

에토 연구 아카이브

현장 사례와 논문은 따로 모으고, 검토 상태·자료 활용 권한·사회정서교육 역량을 구별합니다.

🖥️ 브라우저 보관
🔒 온라인 저장을 설정한 경우, 연구 자료를 열람하려면 먼저 ☁️ 저장 설정에서 연구자 로그인을 해주세요.

🏫 교실에서 발견한 이야기

한국형 사회정서교육(K-SEL) 6대 역량에 따라 50건을 다시 분류한 연구 초안입니다. 교육부·교육청 문서의 실제 사건을 발췌한 자료가 아니고, 기관의 승인 답변도 아닙니다. 교사 검토 전 상태이며 온라인 AI 자료로 자동 공개하지 않습니다.

🔍 에토의 분류 기준과 연구 단계 보기

학교상담 문제 유형은 고민이 무엇인지, K-SEL 역량은 어떤 사회정서적 도움이 필요한지, 도덕과 가치관계 영역은 어떤 교육적 판단의 관점이 관련되는지를 따로 기록합니다. 주역량 1개·보조역량 1개는 연구자가 제안한 임시 배정이며, 안전 문제에서는 SEL보다 보호·절차를 먼저 적용합니다.

공식 자료 원문 대조·저작물 이용 조건 검증·교사 승인 전에는 전문 상담이나 행정 절차에 관한 최종 근거로 사용하지 않습니다.

📚 읽고, 이해하고, 연결하기

논문과 문헌은 서지정보·직접 작성한 요약·활용 한계를 기록합니다. 아래 공식 교육자료 4종은 사례 재구성에 참고한 발행처 목록이지, 해당 자료의 본문 전체나 검증 완료된 연구 요약이 아닙니다.

🌿 현장 사례 기록

식별 가능한 실제 사건 원문은 입력하지 마세요. K-SEL 역량은 검토 가능한 분류 가설이며, 기본 제공 50건은 복사하여 검토할 수 있습니다. 승인·공개 전에는 AI 서버에 참고자료로 전달되지 않습니다.

공개는 온라인 연결 상태에서만 가능합니다. 승인·권한 확인·식별정보 제거가 선행되어야 합니다.

연결 상태

오프라인 모드

온라인 계정의 자료는 사용자별 접근권한(RLS)으로 분리됩니다. 학교 공용 컴퓨터에는 로그인하지 마세요.

⚠️ 처음 계정을 만들면 이메일 확인이 필요할 수 있습니다. Supabase Dashboard에서 데이터베이스 SQL을 먼저 적용해야 저장됩니다. 비밀번호와 서버 관리자 키(service_role)는 HTML에 넣지 마세요.

동기화 도구

중요: 기존 기기의 자료를 먼저 JSON으로 백업한 후 동기화하세요. 온라인 자동 저장은 로그인 이후에 수정한 개별 자료에만 적용됩니다.

✨ AI 연결

서버에 OpenAI API 키를 안전하게 설정하고 Edge Function을 배포하면 AI 답변 버튼이 활성화됩니다. AI는 오직 **교사 검토 완료 + 별도 공개 승인**을 받은 연구자료만 검색해 참고하도록 구성되어 있습니다. 대화 내용은 아카이브에 자동 저장되지 않습니다.
